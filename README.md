# Blog Post Page

A simple, semantic HTML blog post page built as part of the
[Blog Post Page project on roadmap.sh](https://roadmap.sh/projects/blog-post-page).

## Overview

This project demonstrates how to structure a blog post using semantic HTML
elements, including:

- `header` and `nav` for site branding and navigation
- `main` and `article` for the primary page content
- Headings to organize the article hierarchy
- `figure` and `figcaption` for image and quotation content
- `code` and `pre` for inline and block code examples
- `footer` for copyright information

## Files

- `blog.html` - The blog post page
- `image.png` - The image used in the article

## How to View

1. Clone or download this repository.
2. Open `blog.html` in a web browser.

No build tools or dependencies are required.
